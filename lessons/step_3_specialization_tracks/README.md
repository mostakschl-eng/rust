# Step 3: Specialization Career Tracks

Choose the career track that aligns with your software engineering goals:

---

## 🎯 The Three Specialization Tracks

### 🌐 Track A: High-Performance Web Backends & REST APIs
* **`axum`**: Modern web framework built on Tokio and Tower. Type-safe routing, extractors, and middleware.
* **`sqlx`**: Truly async, compile-time checked SQL queries with zero runtime overhead against PostgreSQL, MySQL, and SQLite.
* **`reqwest`**: Making HTTP GET, POST, and PUT calls to third-party APIs.
* **`jsonwebtoken` (JWT)**: Building secure token-based user login and authorization systems.

---

### 🛠️ Track B: Command-Line (CLI) & DevOps Utilities
* **`clap` (v4)**: Parsing terminal flags, subcommands, arguments, and auto-generating beautiful `--help` menus.
* **`ratatui`**: Building rich, interactive terminal user interfaces (TUIs) with charts, lists, and widgets.
* **`indicatif`**: Beautiful loading spinners and progress bars for long-running scripts.

---

### ⚙️ Track C: Systems, Networking & WebAssembly (Wasm)
* **`wasm-bindgen` & `yew`**: Compiling Rust code to WebAssembly to run high-performance logic directly inside web browsers.
* **`tonic`**: High-performance gRPC microservices and protobuf messaging.
* **`tokio-tungstenite`**: Real-time bi-directional WebSocket communication.
